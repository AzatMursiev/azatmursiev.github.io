# azatmursiev.github.io

Страница-визитка: **https://azatmursiev.github.io/**

Один экран без прокрутки — аватар, имя, род занятий и четыре ссылки.
Статика без зависимостей: один `index.html` с инлайновым CSS, иконки —
инлайновый SVG, аватар лежит рядом файлом. Светлая и тёмная темы
подхватываются из системной настройки.
